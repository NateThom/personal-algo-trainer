Guide — how to use AlgoTrainer

AlgoTrainer is a closed learning loop for one motivated learner. It doesn't just hand you problems — it diagnoses your weak patterns, schedules spaced re-practice of novel instances, grades you honestly, tutors you Socratically, and tracks genuine mastery. The whole loop is:

cold problem → recall gate → judge → tutor grade → reschedule → mastery update → repeat

The tutor is Claude Code, not a paid API

The Socratic tutor and grader is a Claude Code skill committed inside this repo (.claude/skills/algotrainer-tutor/). The web app and Claude Code share the filesystem: the app writes a session file describing your attempt, you ask Claude Code to grade it, and it writes a verdict the app reads back. This uses your Claude subscription — there is no per-call API cost — and keeps the tutor a version-controlled part of the project. The trade-off is one deliberate seam: you step over to the Claude Code pane for the grading moments. For a learner already living in Claude Code, that's a natural boundary.

A single practice session, step by step

  1. Get a problem. On the Solve page a problem is served cold — deliberately with no pattern label. Recognising the pattern yourself is the skill interviews test.
  2. Recall gate (before you code). Name the pattern, sketch your approach in a sentence or two, and predict time/space complexity. This forces active retrieval — the single highest-value habit — and it's scored (naming the wrong pattern is what surfaces the "memorizing, not recognizing" flag later).
  3. Write your solution in the editor.
  4. Get a hint (optional). The Get hint button reveals one graduated tier at a time: category → invariant → pseudocode → worked step. Using any hint caps your grade at hard — hints are a safety net, not a shortcut.
  5. Run tests. Your code runs in a separate judge process (with a 5-second timeout) against the problem's tests.
  6. Send to tutor. This saves sessions/session-<id>.json and shows you the session id.
  7. Grade it in Claude Code. In this repo, say:
    Use the algotrainer-tutor skill to grade session <id>
    The skill reads your attempt and the reference solution, then decides a grade (again / hard / good / easy), the approach you actually used, an error-taxonomy code, whether your complexity was optimal, a self-explanation score, and short Socratic feedback — and writes sessions/verdict-<id>.json.
  8. Ingest verdict. Back in the app, click Ingest verdict. This updates your spaced-repetition schedule (FSRS), your per-pattern mastery, and the error journal.

The two ways to use the tutor skill

Ask Claude Code…What it does
"grade session <id>"Reads the session, writes a schema-valid verdict the app ingests.
"generate an arrays-hashing variant (medium)"Authors a brand-new problem for that pattern and saves it (only if its reference solution passes its own tests). Click Reload problems in the nav to bring it into rotation.

Offline / automated fallback: python scripts/stub_tutor.py sessions <id> writes a mechanical verdict when you're away from Claude Code (this is what the test suite uses).

The rhythm that actually builds skill

  • Come back regularly. The scheduler decides what's due — it resurfaces patterns at expanding intervals, right as you're about to forget them. Short, frequent sessions beat marathons.
  • Trust the order. The app serves due reviews before brand-new material (retention first), starts a new pattern in a focused block, then interleaves it with confusable patterns once it matures.
  • Watch the Dashboard. It shows mastery per pattern, what's due, and your error trends — your map of where to push next.
  • Reset (top-right) wipes your progress to start fresh; your problems and any generated variants are kept.
